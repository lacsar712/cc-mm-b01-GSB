# 矿井瓦斯班测台

检查员上报测点甲烷浓度。上报分两段：先按当前表单字段申请挑战码（短时数字码，用过即废），再带同一挑战码提交；提交字段与申请时不一致会被拒绝。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 填好测点和浓度，先点"申请挑战码"拿到数字码，再点"上报"写入，总表多一行。
3. 申请挑战码后把浓度改掉再提交，会被拒绝且行数不变；改回原字段用同一挑战码提交则成功。
4. 再开一个浏览器窗口同时看列表，上报成功时两个窗口都会出现新记录；校验失败不会推送。
5. viewer 登录后没有上报表单，也看不到申请挑战码入口。
